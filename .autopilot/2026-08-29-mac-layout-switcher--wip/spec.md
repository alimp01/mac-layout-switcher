# Спецификация: Mac Layout Switcher («свой аналог Punto/Caramba»)

## Задача

Илья печатает по-русски и по-английски вперемешку. Регулярно текст набирается
не в той раскладке: «ghbdtn» вместо «привет». Punto Switcher для Mac заброшен
Яндексом с 2017 года и на современных macOS не работает; Caramba Switcher жива,
но закрыта и по подписке. Нужен свой инструмент, который сам замечает и
исправляет такие ошибки — и который мы контролируем полностью.

## Решение

Меню-бар приложение для macOS (Swift, без Xcode-проекта — чистый SwiftPM).
Слушает клавиатуру системно, определяет, что слово набрано не в той раскладке,
автоматически переключает раскладку и перепечатывает слово. Option — ручное
исправление последнего слова и откат авто-исправления. Плюс автозамена по
пользовательским шаблонам и озвучка клавиш. Дневника нет.

Сводка по эталонам (исследование 2026-08-29, источники в отчёте агента):

- **Punto Mac (Яндекс)**: авто по словарям + Option для последнего слова,
  автозамена, звуки; последняя сборка 2.1.2 (2017), проект заморожен.
- **Caramba (Москалёв)**: только автоматика, самообучение, автопауза на паролях
  и в терминалах, фиксированные хоткеи (Option — конвертация, DoubleShift и др.);
  жива, ~$6/год.
- **Open-source ориентиры**: RuSwitcher (habr.com/ru/articles/1050394 — разбор
  UCKeyTranslate + синтетические события с маркером), keyswitcher/«Q*Й»
  (статистика + самообучающиеся исключения, откат по Option), helm_switch.

## Решения по реализации

- **Язык/сборка: Swift 5.9+, SwiftPM, без Xcode-проекта** — потому что ядро
  (детектор, конвертер, шаблоны) компилируется и тестируется на Linux, а
  системный слой закрыт `#if os(macOS)`; пользователь собирает одной командой.
- **Перехват: CGEventTap** (`.cgSessionEventTap`, listen-only для набора,
  active для Option-хоткея и автозамены) — единственный способ видеть ввод
  во всех приложениях; требует Accessibility + Input Monitoring (TCC).
- **Определение символов: UCKeyTranslate** по активной раскладке — никакой
  зашитой таблицы под конкретную клавиатуру (подход RuSwitcher).
- **Конвертация RU↔EN: статическая пара карт ЙЦУКЕН↔QWERTY** в ядре — для
  детектора и конвертации строк (двунаправленная, с пунктуацией `;:'"[]{},.<>`).
- **Детектор: правила невозможных сочетаний + биграммные частоты** RU и EN,
  зашитые в код таблицами (сгенерированы заранее), + пользовательские
  исключения (JSON). Порог уверенности; слова короче 3 символов не трогаем.
  Нейросети нет — детерминированно и тестируемо.
- **Исправление: Backspace ×N синтетическими CGEvent + перепечатка** в новой
  раскладке; свои события помечаются магическим значением в
  `eventSourceUserData`, чтобы event tap их не обрабатывал (защита от цикла).
  Буфер обмена не трогаем.
- **Смена раскладки: TISSelectInputSource** (HIToolbox), поиск источников
  RU/EN через `TISCreateInputSourceList`.
- **Состояние/настройки: JSON в `~/Library/Application Support/MacLayoutSwitcher/`**
  (config.json — тумблеры, исключения-приложения; snippets.json — шаблоны;
  exclusions.json — слова-исключения). Редактирование шаблонов — пункт меню
  «Открыть snippets.json» (без отдельного GUI-редактора в этой версии).
- **Звуки: NSSound + системные AIFF** (или свои короткие сэмплы в ресурсах).
- **UI: NSStatusItem + NSMenu**, без SwiftUI-окон — минимальная поверхность.
- **Автопауза: `IsSecureEventInputEnabled()`** для паролей + список bundle-id
  (Terminal, iTerm2, VS Code — по умолчанию, редактируется в config.json).
- **Минимальная macOS: 13 (Ventura)**, Intel + Apple Silicon (universal не
  требуется — сборка на машине пользователя под её архитектуру).

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `SwitcherCore.KeyMap` | карты ЙЦУКЕН↔QWERTY | `convert(_ s: String, to: Lang) -> String`, `enum Lang { case ru, en }` | сами таблицы соответствий |
| `SwitcherCore.Detector` | правила + биграммы + исключения | `verdict(for word: String) -> Verdict` (`enum Verdict { case ru, en, unsure }`), `addExclusion(_:)`, `isExcluded(_:)` | частотные таблицы, пороги |
| `SwitcherCore.SnippetStore` | шаблоны автозамены | `expansion(for abbrev: String) -> String?`, `load(from url:)` | формат хранения |
| `SwitcherCore.WordBuffer` | текущее набираемое слово | `append(char:)`, `boundary()`, `backspace()`, `var word: String`, `reset()` | правила границ слова |
| `app.EventTap` | перехват CGEvent | `start(handler:)`, `stop()`, маркер синтетики | создание tap, восстановление после timeout |
| `app.Typist` | синтетический ввод | `replaceLastWord(with: String, len: Int)` | Backspace-последовательность, маркировка событий |
| `app.LayoutSwitcher` | системная раскладка | `current() -> Lang?`, `select(_ lang: Lang)` | TIS API |
| `app.Engine` | оркестрация: буфер→детектор→исправление, откат, автопауза | `handle(keyEvent:)` | вся склейка, окно отката 5 с |
| `app.StatusBarUI` | меню и тумблеры | `show(state:)`, колбэки тумблеров | NSStatusItem |
| `app.Config` | config/snippets/exclusions JSON | `load()`, `save()`, типизированные поля | пути, миграции |

**Шов для тестов — один: `SwitcherCore`.** Всё поведение детектора, конвертера,
буфера слова и шаблонов проверяется юнит-тестами через публичные сигнатуры ядра,
на Linux. Системный слой (`app.*`) тестами не покрывается — он проверяется
приёмкой на Mac пользователя (R07i: у агента macOS нет).

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Дневник (запись набранного) | пользователь не выбрал на брифинге; по сути кейлоггер |
| Самообучение как у Caramba (автоматическое) | вместо него — исключения с ручным пополнением + автодобавление при откате (история 5); полноценное самообучение — следующий заход |
| GUI-редактор шаблонов | шаблоны редактируются как JSON из меню; отдельное окно — следующий заход |
| Подпись/нотаризация .app, автообновление | сборка личная, на своём Mac; Gatekeeper обходится правым кликом → Open |
| Другие пары языков (DE и т.п.) | в брифе только аналог для RU/EN-сценария; ядро расширяемо через `Lang` |
