## Детали

- `main.swift`: NSApplication без Dock-иконки (`.accessory`), старт EventTap
  после проверки Permissions; нет доверия → пункт меню и алерт с кнопками
  «Открыть настройки» (обе панели), объяснение по-русски.
- `StatusBarUI`: NSStatusItem, иконка — SF Symbol (например «keyboard»),
  приглушённая в паузе. Меню: Пауза/Работа; Автопереключение вкл/выкл;
  Звуки вкл/выкл; Открыть snippets.json; Открыть config.json; О программе
  (версия + «аналог Punto/Caramba, свой»); Выход. Тумблеры пишут Config
  сразу (persist).
- `Sounds`: звук на keyDown (тихий клик), отдельный звук на автоисправление,
  третий — на откат. Системные звуки macOS (NSSound(named:) — Tink/Pop/…)
  — без своих ресурсов; выбор имён — константами.
- `build.sh`: `swift build -c release` + сборка `MacLayoutSwitcher.app`
  (Contents/MacOS + Info.plist: LSUIElement=true, bundle id
  `space.alimp.maclayoutswitcher`, версия) + `codesign --force --deep -s -`
  (ad-hoc). Вывод: путь к .app и что делать дальше.
- `README.md` (по-русски): что это; чем отличается от Punto (заброшен с 2017)
  и Caramba (закрыта, подписка) — 5–6 строк из spec «Решение»; требования
  (macOS 13+, Swift toolchain / Xcode CLT: `xcode-select --install`);
  сборка `./build.sh`; первый запуск и выдача разрешений (Accessibility +
  Input Monitoring, пошагово); горячая клавиша Option и откат; шаблоны
  (snippets.json, формат с примером); **чек-лист ручной приёмки на Mac**
  (10–12 пунктов: ghbdtn→привет в TextEdit, валидные слова не тронуты,
  Option-конвертация, откат, пароль в Safari молчит, Terminal молчит,
  сниппет, звуки, перезапуск сохраняет настройки).
- CLAUDE.md: обнови таблицу «Команды» реальными командами (между маркерами
  autopilot менять можно только команды — остальное не трогай).
