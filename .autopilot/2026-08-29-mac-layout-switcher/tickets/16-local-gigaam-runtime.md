# 16 — Локальная расшифровка WAV через GigaAM v3

**Требование:** G14
**Blocked by:** None — can start immediately
**Status:** ready-for-agent

## Что должно заработать

Готовая .app содержит нативный SpeechRecognizer: WAV → настоящий текст GigaAM v3 E2E полностью офлайн. В SwiftPM закреплена зависимость, Linux и Intel сборки не тянут Apple arm64 binary. Модель загружается штатным сервисом с прогрессом, отменой, проверкой хэшей и атомарной установкой; для проверки сервис доступен приложению T17.

Спецификация: ../speech-spec.md, технические решения и артефакты обязательны. Зона: Package.swift/Package.resolved, Sources/SpeechRecognizer, новые файлы System/SpeechModelStore.swift и System/SpeechRecognitionProcess.swift, build.sh, лицензии, README раздел backend, ADR 0012. Не трогать Engine/UI/main/config — T17.

- [ ] CLI helper принимает model-dir + относительный WAV, выдаёт JSON текст/ошибку, nonzero при ошибке; настоящий GigaAM, не stub.
