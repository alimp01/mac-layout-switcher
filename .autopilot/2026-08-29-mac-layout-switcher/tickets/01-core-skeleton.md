## Что должно заработать

Проект собирается `swift build` и тестируется `swift test` на Linux (ядро) —
структура пакета такова, что macOS-слой добавится следующими тасками, не ломая
Linux-сборку ядра. Ядро умеет: конвертировать строку между раскладками
ЙЦУКЕН↔QWERTY в обе стороны (с пунктуацией `;:'"[]{},.<>` и `ёЁ~`),
накапливать текущее набираемое слово из потока символов и находить
разворачивание шаблона по сокращению.

## Детали

- Package.swift: библиотека `SwitcherCore` (без зависимостей, компилируется на
  Linux и macOS), executable `MacLayoutSwitcher` **только** под macOS
  (`#if os(macOS)` внутри исходников; сам target объявлен всегда, но его
  исходники целиком под гвардом — чтобы `swift build --target SwitcherCore`
  и `swift test` работали на Linux). Если условная компиляция executable на
  Linux мешает `swift test`, допустимо объявить executable через
  `.target(..., exclude:)`-приёмы или проверку платформы в Package.swift —
  главное: на Linux `swift test` зелёный.
- `Lang`: `enum Lang { case ru, en }`.
- KeyMap: полная двунаправленная карта символов по физическим клавишам
  ANSI-клавиатуры, оба регистра. `convert("ghbdtn", to: .ru) == "привет"`,
  `convert("привет", to: .en) == "ghbdtn"`. Символы вне карты — без изменений.
- WordBuffer: `append(char:)`, `backspace()`, `boundary()` (сбрасывает слово),
  `reset()`, `var word: String`. Границы слова: пробел, табуляция, перевод
  строки, и позже решит Engine — буфер лишь исполняет.
- SnippetStore: `load(from url:)` (JSON `{"сдр": "С днём рождения!"}`),
  `expansion(for:) -> String?`. Отсутствующий/битый файл = пустой набор, не
  падение.
- Тесты XCTest на всё выше (конвертация обоих направлений, регистры,
  пунктуация, буфер с backspace, сниппеты, битый JSON).
- Заготовка README.md: название, одна строка о проекте (дописывается в 05).

## Критерии приёмки

- [ ] `swift build` и `swift test` зелёные на Linux
- [ ] `convert` двунаправленный, регистры и пунктуация покрыты тестами
- [ ] WordBuffer корректен при backspace за границу слова (пустое слово, не крэш)
- [ ] SnippetStore переживает отсутствующий и битый JSON
- [ ] Структура пакета допускает macOS-only executable без поломки Linux-тестов
