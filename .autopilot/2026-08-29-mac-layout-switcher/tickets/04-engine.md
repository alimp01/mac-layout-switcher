## Что должно заработать

исправление; Option — ручная конвертация последнего слова; Option сразу после

## Детали

- **Максимум логики — в `SwitcherCore` (платформонезависимо, под тесты).**
  Введи в ядре `EngineCore`: принимает абстрактные события
  (`char(Character)`, `backspace`, `boundary(Character)`, `optionTap`) и
  возвращает команды (`replaceLast(len:with:switchTo:)`, `expandSnippet(...)`,
  `none`). macOS-Engine лишь транслирует CGEvent ⇄ EngineCore и исполняет
  команды через Typist/LayoutSwitcher. Тесты EngineCore — на Linux.
- **Автоисправление:** решение на границе слова (пробел/enter/таб/пунктуация).
  Слово завершено → Detector; вердикт `.ru`/`.en` и раскладка не совпадает со
  словом → заменить слово конверсией + переключить раскладку. Разделитель
  сохраняется (заменяется только слово). Автоповтор и слова с модификаторами
  Cmd/Ctrl — сброс буфера, не исправление.
- **Option-хоткей:** одиночное нажатие-отпускание Option (flagsChanged down→up
  без других клавиш между ними) → конвертировать последнее завершённое слово
  безусловно (без детектора), переключить раскладку. Повторный Option —
  конвертация обратно.
- **Откат:** если последнее исправление было автоматическим и Option нажат в
  течение 5 с → вернуть как было, слово — в исключения Detector (persist).
- **Автозамена:** слово совпало с сокращением из SnippetStore → на границе
  слова заменить на разворот (приоритет выше детектора; после разворота
  детектор к этому слову не применяется).
- **Автопауза:** SecureInput активен → молчать полностью. FrontApp.bundleID в
  списке исключений → молчать. Дефолтный список: `com.apple.Terminal`,
  `com.googlecode.iterm2`, `com.microsoft.VSCode`.
- **Config:** JSON в `~/Library/Application Support/MacLayoutSwitcher/`
  (config.json: autoSwitch, sounds, excludedApps; snippets.json;
  exclusions.json). `load()`/`save()`, дефолты при отсутствии файлов,
  битый файл → дефолты + бэкап битого рядом (`.broken`).
- Глобальный тумблер autoSwitch=false → авто молчит, Option-хоткей работает.

- [ ] EngineCore-тесты на Linux: сценарии «ghbdtn␣»→«привет␣», валидное слово не тронуто, откат по Option в окне 5 с + слово в исключениях, повторная конвертация по Option, сниппет разворачивается, пауза в secure input
- [ ] Автоисправление только на границе слова; разделитель сохраняется
- [ ] Cmd/Ctrl-комбинации и автоповтор не порождают исправлений
