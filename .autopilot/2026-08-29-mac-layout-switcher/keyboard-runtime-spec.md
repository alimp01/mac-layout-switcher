# G20 — восстановить Option и автоматическую замену

## Доказательства
InputFocusGuard не включает ленивое AX-дерево приложения; требует AXSelectedText setter, доверяет его success без readback. Native fixture с неизменённым production Target воспроизводит отказ отсутствующего setter и ложный успех no-op setter. G19 исправил только диктовку. Нет cached ticket → Option отвергается до свежего захвата. Пустой буфер → .none без переключения. Первый асинхронный bind сбрасывает буфер. Обычный набор через CUA в отдельном TextEdit остался Ghbdtn; это synthetic-input baseline, не hardware acceptance.

## Поведение и приёмка
1. Option: выделение имеет приоритет; иначе текущее/последнее слово и существующий undo; если исправлять нечего — переключить RU/EN. Это рабочее допущение, уточнение пользователю отправлено. Недоступное/защищённое поле не разрешает слепую перезапись. Не показывать просьбу выделить текст для нормального сценария без выделения. Явное переключение источника не требует записи в поле.
2. Автозамена ghbdtn → привет до разделителя в доступном native/Electron поле; сохранить короткие слова/сниппеты/undo и настройки exclusions. Захват вне event tap: bounded bootstrap/fresh focus lookup, не терять первое слово из-за bind. Привязка к конкретному элементу/PID, не только приложению.
3. Проверяемая замена общей низкоуровневой границей для keyboard и G19, либо минимальным переиспользованием. Проверить exact source UTF16 + границу предыдущего слова, исходное выделение и разрешение непосредственно перед записью. После записи проверить текст/каретку; .success setter и CGEvent.post недостаточны. Нет AXValue whole-field rewrite, clipboard или backspace loops.
4. Отменённый запрос/смена поля/навигация/secure input не оживают. ozon после смены поля не получает чужого префикса. При частичной/неподтверждённой записи не повторять замену. Результат различает confirmed / untouched / uncertain. Не отправлять Enter/Tab автоматически после uncertain частичной замены; явно сообщить, что отправка остановлена, слово надо проверить. При untouched безопасном отказе физический разделитель сохранить по существующей политике, пробел не дублировать. Сохранить flags Shift+Enter и очередность быстрой печати; не терять последующие физические символы молча.
5. Регрессии на реальном production пути: lazy focus, отсутствующий/no-op setter, verified Unicode, выделение/слово/undo/пустой буфер, stale prefix, фокус/permit, partial delivery, разделители/flags. Не выдавать mocked AX за проверенную доставку в Codex. Existing G19 harnesses и полный core suite зелёные; native full release, два независимых ревью.
