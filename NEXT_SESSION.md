# Продолжение работы — Mac Layout Switcher

Проект: аналог Punto/Caramba для macOS, SwiftPM, ядро SwitcherCore без платформенных зависимостей.
GitHub: https://github.com/alimp01/mac-layout-switcher

Сначала прочитай `CLAUDE.md`, `.autopilot/state.js`, затем manifest и актуальные тикеты в `.autopilot/2026-08-29-mac-layout-switcher/`. Они определяют состояние ревью и релиза; VERSION сам по себе не доказывает публикацию.

## Изменения для 1.4.2 (G19, 08.10.2026)

- Воспроизведена причина пустой панели: NSTextView/document container имели нулевую ширину. Исправлено явное sizing после Auto Layout; длинный результат выделяется и прокручивается. Production AppKit harness дал red на 1.4.1 и green после изменения.
- DictationTarget: ограниченный Electron AXManualAccessibility bootstrap, точный исходный элемент/диапазон/значение, причина отказа. Нельзя подменять отсутствующее выделение CFRange(0,0), писать полное AXValue или автоматически трогать clipboard.
- Permit создаётся при физическом удержании до async capture; ввод, клик, activation и AX-изменения аннулируют его без восстановления. Во время одной собственной записи допустимы ограниченные ожидаемые AX-уведомления; фокус и физические события всегда отменяют продолжение.
- Native AXSelectedText + readback; Chromium/Electron framework routing (включая реально установленный Codex Framework) выбирает guarded Unicode заранее, без пробной мутации. Порции подтверждаются точным value/caret, частичная/неясная доставка не повторяется, полный текст сохраняется с предупреждением. AX/CGEvent не транзакция; пределы проверки описаны README.
- `tools/test-dictation-panel.sh` и `tools/test-dictation-adapter.sh`: собственный AppKit/AX fixture, без микрофона, TCC и ввода в пользовательские поля. Фактическая приёмка установленного Codex не подтверждена. Полный Linux/native release, ревью и публикацию фиксирует root в state/QA.

## Изменения для 1.4.1 (G18, 07.10.2026)

- Общая логика для восьми однобуквенных RU-слов, 41 подтверждённое словарное дополнение, защиты файл/BBC/BRB/RFC/XML. Пороги биграмм не менялись; ShortWords сохраняет предел 1–4, длинные дополнения ограничены отдельным списком Detector.
- Реальные пары ns↔ты, jq↔ой, herb↔руки, tv↔ем, ev↔ум, ble↔иду требуют контекста. Свежие ns/jq теперь сохраняются; прежние jr/ye/tot остаются предпочтением RU.
- Безопасная грамматика: слово, опциональные вложенные круглые скобки, затем суффикс !?. `(yt!)` и некорректные/внутренние скобки не распознаются. Физическая пунктуация RU-карты не обрезается. Bare-исключение защищает обёртки; undo учит исходный токен целиком.
- WordCoverageTests содержит независимые literal пары, регистр, контекст, отрицательные примеры и EngineCore expectedText/space/Enter/Tab/undo/reset/pause. Базовый и финальный диагностические наборы с фиксированными знаменателями — `.autopilot/2026-08-29-mac-layout-switcher/audit/word-coverage/`. Это конечный набор, не оценка реальной точности.
- Targeted red/green на Linux: single-letter 12 failures → 0, lexical/collisions 446 → 0, wrappers 14 → 0. Финальные suite/build/review/release доказательства ведёт root в state/QA; не считать VERSION публикацией.

## Изменения для 1.4.0 (07.10.2026)

- Контекст ввода и отмены сбрасывается при смене поля/приложения, клике и навигации. Перед исправлением проверяется исходный текст и поле; замена одним AXSelectedText не оставляет наполовину удалённое слово. Поддержка зависит от редактируемых AX-атрибутов приложения.
- `ozon` не меняется; `b/B` и `z/Z` исправляются в `и/И` и `я/Я` без обязательного русского контекста, а `plan b` остаётся английским.
- Существующее сочетание конвертации (по умолчанию одиночный Option) сначала исправляет выделение. Регистр, пробелы, переносы, цифры и неизвестные символы сохраняются; буфер обмена и Enter не используются. Без выделения сохраняется проверенная конвертация/откат слова. Недоступное выделение не запускает старый откат; показывается объяснение. Обычная клавиша сочетания подавляется вместе с keyUp.
- Диктовка автоматически проверяет/готовит модель при первом использовании; служебный optimized_cache разрешён. Отмена/ошибка не вызывают бесконечного повторения. После загрузки или разрешения микрофон требует нового удержания сочетания.

## Проверки и ограничения

Linux-тесты: изолированная копия в `/tmp` на `claudebot-server`; Swift — `/home/claudebot/swift-toolchain/swift-6.0.3-RELEASE-ubuntu24.04/usr/bin`. На Mac доступны native debug/release build, XCTest в текущих CLT недоступен. Не переносить результат Linux-тестов или компиляции в статус успешной UI-приёмки.

Живые выделение/ввод в сторонних приложениях и микрофон без отдельного запроса не трогать. Текущий командный процесс не имеет Accessibility trust, поэтому положительная AX-приёмка на реальных полях остаётся ручной. Проверить многострочное выделение, кириллицу/латиницу/смешанный текст, смену поля/выделения во время ожидания, неподдерживаемое поле, обычное сочетание keyDown/keyUp, быстрый ввод и отмену подготовки модели.

Релизом и отдельными коммитами тикетов управляет root после двух независимых ревью. Обязательны VERSION, push и обновление публичного архива по инструкции CLAUDE.md. Ad-hoc обновления могут требовать повторных разрешений macOS. Для проверяемого DMG использовать MLS_DIST_DIR вне iCloud Documents.
