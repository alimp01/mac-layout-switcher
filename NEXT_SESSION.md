## Как здесь работают
- Сборка ведётся навыком `/autopilot`. Любая доработка = запись в бриф («Дополнения») + строка `G##` в манифесте + тикет + субагент-исполнитель + ревью (двое ревьюеров) + коммит. **Оркестратор код проекта не пишет** — только `.autopilot/`, `CLAUDE.md`, git.
- Swift на сервере не в PATH: `export PATH=/home/claudebot/swift-toolchain/swift-6.0.3-RELEASE-ubuntu24.04/usr/bin:$PATH`. `swift test` → сейчас **58 тестов** зелёные. Ядро `SwitcherCore` тестируется на Linux; весь macOS-слой под `#if os(macOS)` собирается **вслепую** — e2e только на Mac Ильи.
- **Ритуал релиза (обязателен):** бампни `VERSION` → commit → `git push` → `git archive --format=tar.gz --prefix=mac-layout-switcher/ -o /var/www/cat.alimp.space/mac-layout-switcher.tar.gz HEAD`. Без бампа VERSION приложения обновление не увидят. Автообновление читает raw `VERSION` с main.
- Доступ к Mac Ильи: Chrome-расширение Claude (когда подключено) — `file:///Users/ilyaalimpiev/...`; иначе computer-use в фоне (например, `Консоль` → «Отчёты журналов» показывает `~/Library/Logs`). Лог обновлений: `~/Library/Logs/MacLayoutSwitcher-update.log`.
