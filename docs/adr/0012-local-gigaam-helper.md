# ADR 0012: локальная диктовка GigaAM v3 в отдельном процессе

Статус: принято, G14 / T16 (2026-09-16).

## Контекст

Диктовка должна работать локально, в том числе без интернета после первой
загрузки модели. Пользователю готовой .app не нужны Python, Homebrew или
дополнительный сервер. Правило «без внешних зависимостей» (ADR 0001/0002)
получает узкое исключение для заказанной пользователем ML-функции;
детектор раскладки остаётся самостоятельным и детерминированным.

## Решение

SwiftPM закрепляет GigaSTT **ровно 2.17.0**, commit
`e66dbd0b44fbc89b4ffdf283f7435400c0129b7b`; Package.resolved хранится в Git.
SwiftPM проверяет SHA256 XCFramework:
`97718a3dde9b1678539a7ec095de6d52da691c4340b093db5df20ba55542a185`.
В manifest зависимость и target существуют только на macOS arm64.
Intel и Linux не разрешают эту зависимость и не скачивают XCFramework.
Для явной cross-сборки Intel на arm64-хосте задаётся `MLS_DISABLE_SPEECH=1`.

Основной executable сохраняет minimum macOS 13.0 и не линкуется с GigaSTT.
Отдельный `Contents/Helpers/SpeechRecognizer` собирается для macOS 13.4:
часть статических объектов XCFramework требует именно 13.4, несмотря на
13.0 в upstream Package.swift. Сервис проверяет архитектуру и версию ОС
до запуска; на неподдерживаемом Mac переключатель раскладки продолжает
работать. `otool -l` проверен: main minos 13.0, helper minos 13.4.

Helper принимает абсолютный каталог модели и basename WAV, выдаёт один
JSON (`text` при успехе, `error` при сбое) и соответствующий exit status.
Вызов `GigaSTT.Engine(modelDir:poolSize: 1).transcribeFile(path:)` выполняет
настоящий E2E RNNT. Upstream FFI отвергает абсолютный путь WAV, `..` и выход
через symlink из CWD. Поэтому родитель делает приватную копию записи,
устанавливает `Process.currentDirectoryURL` и передаёт `recording.wav`.
CWD основного приложения не меняется. Исходный WAV остаётся собственностью
вызывающего кода; тот удаляет его после completion.

У процесса собственная последовательная очередь. stdout и stderr читаются
неблокирующими bounded reads, максимум 64/32 KiB; stderr не сохраняется и
не логируется. Таймаут по умолчанию 180 секунд. Отмена/таймаут сначала
посылают SIGTERM, через 0,5 секунды при необходимости SIGKILL. Все пути
завершения удаляют приватный каталог. `shutdown(completion:)` позволяет
дождаться этой очистки при выходе приложения. Callback всегда на main,
устаревшие сессии дополнительно отсекаются контроллером диктовки.

Веса — четыре закреплённых файла `v3_e2e_rnnt_*`, всего **232 576 763 байта**,
в `Application Support/MacLayoutSwitcher/SpeechModels/gigaam-v3-e2e-2026-06-22/`.
Загрузка начинается только через явный `download`, использует ephemeral
URLSession, идёт последовательно во временный каталог на том же диске.
Для каждого файла проверяются точный размер и SHA256; статус готовности
также требует полного повторного хэширования и точного набора файлов.
Это не позволяет дополнительному encoder/manifest изменить выбранную модель.
Публикация каталога атомарна (`rename` либо `RENAME_SWAP` при замене).
Обновление .app не затрагивает веса. Отмена/ошибка удаляет staging; исходная
готовая модель сохраняется до успешной атомарной замены.

## Длинные записи и проверка

Проверен pinned Rust source `221425f90cd88d013bf23d8715d499f304e33ac3`:
file pipeline после 30 секунд использует окна по 24 секунды с перекрытием
2 секунды и объединением слов. Helper не обрезает запись и не использует
streaming API с иной семантикой финализации.

На Mac arm64/macOS 15.6.1 выполнен настоящий ASR с запретом сети через
`sandbox-exec`: публичный русский Golos WAV 4 с — успешный текст; 5 с
тишины — `no_speech`; 69,265 с из 15 разных фрагментов — успешный текст,
включая речь в конце (распознавание отдельных слов отличается от изолированных
фрагментов). Дополнительный WAV 36 с с речью только после 32-й секунды дал
точно тот же результат, что короткий источник: тихой обрезки нет.
Записи, модели и распознанные тексты не входят в репозиторий.

## Лицензии и последствия

В .app включаются лицензии GigaSTT/gigastt, GigaAM, ONNX Runtime и notices
Rust-зависимостей. Upstream XCFramework статически включает ONNX Runtime;
дополнительные dylib не нужны. Консервативный набор Rust notices взят по
upstream release SBOM (включает также неиспользуемые offline-сборкой компоненты);
для MPL-компонентов приведены ссылки на точные исходники и upstream vendor patch.
Никакого облачного fallback или автоматической смены модели нет.
