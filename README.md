# Mac Layout Switcher

Собственный аналог **Punto Switcher** и **Caramba Switcher** для macOS:
приложение в меню-баре, которое само замечает текст, набранный не в той
раскладке («ghbdtn» вместо «привет»), переключает раскладку и перепечатывает
слово. Плюс ручное исправление по Option, автозамена по шаблонам и звуки
клавиш. Дневника (записи набранного) нет.

## Чем отличается от Punto и Caramba

- **Punto Switcher для Mac (Яндекс)** — заброшен: последняя сборка 2.1.2
  вышла в ноябре 2017 года, проект заморожен и на современных macOS не
  работает.
- **Caramba Switcher (Сергей Москалёв, автор оригинального Punto)** — жива и
  полностью автоматическая, но закрытая и по подписке (~$6/год в Mac App
  Store), с самообучением, но без ручных шаблонов.
- **Mac Layout Switcher (этот проект)** — бесплатный и открытый, весь код у
  вас. Автоматика + Option-хоткей для ручной конвертации и отката + автозамена
  по вашим шаблонам + звуки. Без облака, без подписки, без дневника.

## Что умеет

- Автоисправление раскладки по детектору (правила невозможных сочетаний +
  биграммные частоты RU/EN), без ложных срабатываний на коротких/смешанных
  строках и валидных английских словах.
- **Option** (одиночное нажатие-отпускание) — сконвертировать последнее слово
  RU↔EN вручную; **Option сразу после авто-исправления** — откатить его, и
  слово попадает в исключения (больше не трогается).
- Автопауза в полях паролей (secure input) и в приложениях-исключениях
  (по умолчанию Terminal, iTerm2, VS Code — правится в `config.json`).
- Автозамена по шаблонам: «сдр» + пробел → «С днём рождения!».
- Звуки: клик на нажатие, отдельные сигналы на исправление и на откат.

## Требования

- macOS 13 (Ventura) или новее, Intel или Apple Silicon.
- Swift toolchain — Xcode Command Line Tools:

  ```sh
  xcode-select --install
  ```

## Сборка

Одной командой из корня репозитория (на своём Mac):

```sh
./build.sh
```

Скрипт соберёт релиз через SwiftPM, разложит `dist/MacLayoutSwitcher.app`
(с `LSUIElement` — без иконки в Dock) и подпишет его ad-hoc. В конце напечатает
путь и дальнейшие шаги.

Логику детектора можно проверить ещё до сборки .app — на любой машине,
включая Linux (это же гоняет CI сборки):

```sh
swift test
```

## Установка через .dmg

Чтобы получить приложение как полноценный дистрибутив — образ, который
монтируется и ставится перетаскиванием в «Программы», — соберите `.dmg`
(на своём Mac, одной командой):

```sh
./build-dmg.sh
```

Скрипт сначала соберёт `dist/MacLayoutSwitcher.app` через `./build.sh` (если
его ещё нет; `--rebuild` пересобирает принудительно), затем упакует его в
`dist/MacLayoutSwitcher.dmg` с ярлыком «Программы» (Applications) внутри.

Дальше:

1. `open dist/MacLayoutSwitcher.dmg` — смонтировать образ.
2. Перетащить **MacLayoutSwitcher.app** на ярлык **«Программы»** (Applications).

Приложение подписано только ad-hoc (нет Apple Developer ID, нет нотаризации —
это личная сборка), поэтому **первый запуск** после установки:

- В «Программах» **правый клик по MacLayoutSwitcher → «Открыть»** → в диалоге
  Gatekeeper подтвердить «Открыть» (обычный двойной клик macOS может отклонить).
  Это нужно один раз; дальше приложение запускается как обычно.
- Затем выдать те же два разрешения, что и для .app —
  **Универсальный доступ (Accessibility)** и **Мониторинг ввода (Input
  Monitoring)** — см. раздел «Первый запуск и разрешения» ниже.

## Первый запуск и разрешения

1. Запустить: `open dist/MacLayoutSwitcher.app`. Из-за ad-hoc подписи
   Gatekeeper может отказать при двойном клике — тогда **правый клик по .app →
   «Открыть»** (один раз).
2. Приложение слушает клавиатуру во всех программах, поэтому macOS требует два
   разрешения. Приложение покажет подсказку с кнопками; выдать вручную можно
   так:
   **Системные настройки → Конфиденциальность и безопасность →**
   - **Универсальный доступ (Accessibility)** — включить «MacLayoutSwitcher».
   - **Мониторинг ввода (Input Monitoring)** — включить «MacLayoutSwitcher».
3. Перезапустить приложение (пункт меню-бара «Я выдал разрешения» или заново
   `open`). Иконка-клавиатура появится в меню-баре.

## Меню-бар

- **Пауза / Работа** — временно выключить перехват (иконка приглушается).
- **Автопереключение** — вкл/выкл авто-исправление по детектору.
- **Звуки** — вкл/выкл озвучку.
- **Открыть snippets.json / config.json** — правка шаблонов и настроек во
  внешнем редакторе (после правки Engine перечитывает файлы).
- **О программе**, **Выход**.

Все тумблеры пишутся в `config.json` сразу и переживают перезапуск.

## Шаблоны автозамены (snippets.json)

Файл `~/Library/Application Support/MacLayoutSwitcher/snippets.json` — простой
JSON «сокращение → раскрытие». Разворачивается по разделителю (пробел/enter):

```json
{
  "сдр": "С днём рождения!",
  "ттт": "тел.: +7 000 000-00-00"
}
```

Пункт меню «Открыть snippets.json» создаёт файл-заготовку, если его ещё нет.

## Чек-лист ручной приёмки на Mac

После выдачи разрешений прогнать по пунктам (галочка = работает):

1. [ ] В **TextEdit** набрать `ghbdtn` + пробел → превращается в `привет `,
   раскладка переключилась на русскую.
2. [ ] Набрать `cgfcb,j` + пробел → `спасибо ` (пунктуация внутри слова не
   считается границей).
3. [ ] Валидное английское слово `hello` + пробел → **не тронуто**.
4. [ ] Короткие/смешанные строки (`ok`, `id`, `wifi2`, e-mail) → **не тронуты**.
5. [ ] Набрать слово в неправильной раскладке, нажать **Option** → слово
   сконвертировано вручную, раскладка сменилась.
6. [ ] Сразу после авто-исправления нажать **Option** → вернулось как было;
   повторный набор того же слова больше **не** исправляется автоматически.
7. [ ] Поле пароля в **Safari** (secure input) → автоматика молчит, ничего не
   перепечатывается.
8. [ ] **Terminal** (приложение-исключение) → автоматика молчит.
9. [ ] Шаблон `сдр` + пробел → развернулся в «С днём рождения! ».
10. [ ] Включить **Звуки**: слышен клик на нажатие и отдельный сигнал на
    исправление/откат; выключить — тишина.
11. [ ] Поставить **Паузу** — перехват прекращается, иконка приглушена; снять —
    снова работает.
12. [ ] Перезапустить приложение → состояние тумблеров (автопереключение,
    звуки, исключения) сохранилось.

## Границы этой версии

Нет дневника и авто-самообучения (только ручные исключения + автодобавление
при откате), нет GUI-редактора шаблонов (правятся как JSON), нет подписи/
нотаризации (личная сборка на своём Mac). Пары языков — RU/EN; ядро
расширяемо.
